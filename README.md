# AeroStyle Responsive Web Design

Website demo AeroStyle dengan layout responsif dan menu hamburger Pure CSS (tanpa JavaScript).

## Menjalankan
Buka `index.html` di browser atau gunakan Live Server di VS Code.

## Struktur
- `index.html`
- `assets/css/style.css`

## Publikasi
Unggah isi folder ini ke repository GitHub yang digunakan untuk tugas, lalu aktifkan GitHub Pages pada branch utama.
